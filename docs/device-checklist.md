# 実機での確認チェックリスト

画面テスト（Playwright）では確かめられない、端末ごとに差が出る項目です。iPhone と Android の両方で確かめ、結果（OS のバージョン、ブラウザ、うまくいかなかった項目と表示）を Claude に伝えてください。

確認日: ____ 年 __ 月 __ 日

## 1. インストール
| 項目 | iPhone | Android |
|---|---|---|
| ホーム画面に追加できる（iPhone は Safari の共有メニュー、Android は「アプリとして追加」） | ☐ | ☐ |
| ホーム画面のアイコンが欠けずに表示される（Android は丸い枠の中に麻雀牌が収まる） | ☐ | ☐ |
| ホーム画面から開くと、ブラウザの枠なしで起動する | ☐ | ☐ |
| ダークモードで、画面上端（ステータスバー）の色がヘッダーと揃っている | — | ☐ |

## 2. オフライン
| 項目 | iPhone | Android |
|---|---|---|
| 一度開いたあと、機内モードにしてホーム画面から開ける | ☐ | ☐ |
| 機内モードのまま、素点を入れて記録できる | ☐ | ☐ |

## 3. 共有シート
| 項目 | iPhone | Android |
|---|---|---|
| 結果表の「画像シェア」で共有シートが開き、LINE などに画像を送れる | ☐ | ☐ |
| 「URLシェア」で共有シートが開き、送った URL を別の端末で開ける | ☐ | ☐ |
| 「観戦URL」で共有シートが開き、別の端末で開くと途中経過が見える | ☐ | ☐ |
| 「共有の準備ができました／もう一度押すと共有できます」と出た場合、もう一度押すと共有できる | ☐ | ☐ |
| データ管理の「復元キーを表示」→「共有」で、メモアプリなどに送れる | ☐ | ☐ |

## 4. クラウドバックアップとパスキー
同じ Apple ID（または Google アカウント）でログインした、別の端末を用意します（なければ、アプリを一度削除して入れ直します）。

| 項目 | iPhone | Android |
|---|---|---|
| 「クラウドバックアップを始める」で復元キーが表示される | ☐ | ☐ |
| 続けて「パスキーにも保存」で、顔認証や指紋認証のあと「パスキーにも保存済み」と出る（「対応していません」と出た場合は、その旨を記録） | ☐ | ☐ |
| 別の端末（または入れ直したアプリ）で「クラウドから復元」→「パスキーで復元」を選び、成績が戻る | ☐ | ☐ |
| 復元キーを入力して復元できる | ☐ | ☐ |
| 元の端末で「今すぐバックアップ」を押すと、「別の端末に引き継がれた」と出て止まる | ☐ | ☐ |
